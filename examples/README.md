# 示例

当前设计的 [HTML 源文本示例](../docs/design/examples/README.md)演示平级节点与不分类的有向边，包括分支、多入边、平行边、回路、自环、独立节点，以及统一删除前后和空图的格式。这些样例不包含新架构的交互式渲染实现。

首版不提供自动排版，手动摆放、连线更新与保存的设计见[逻辑设计草案](../docs/design/logic.md)。自动排版待手动流程完整可用后，按具体布局场景逐项设计，不恢复图类型字段。
