# HTML 第一版：文件流程里程碑

当前实现是新架构的第一个工程里程碑，不是完整首版编辑器。产品规范仍以 `docs/design/` 为准。

2026-10-16：`1.0.0-alpha.2` 在本机 Chrome 和 Codex 内置浏览器中通过最小文件流程验证。系统文件选择与授权、页面操作及结果观察由用户完成；Agent 核对真实磁盘写入，执行外部原子改盘，并验证源码、资源与哈希。详细证据见[验收记录](../verification/html-milestone/README.md)。

## 构建与检查

在 `app/` 中运行 `npm ci`、`npm run check`、`npm test`、`npm run build`。
安装依赖后，也可在仓库根目录运行 `npm run check`、`npm test`、`npm run build`，或对应的 `check:html`、`test:html`、`build:html` 同义命令。根目录仅转发到本应用，不再包含旧 CLI/WebUI 的入口或依赖。
产物位于 `dist/html/`，包含 `maps/minimal.html` 和固定版本的 `runtime/1.0.0-alpha.2/`。
运行资源为普通 JavaScript 与 CSS；依赖和公式字体已打包，不依赖 CDN、开发服务器或先前缓存。
这是尚未发布的 alpha 构建，构建命令会重新生成模板。实际编辑与验证应先复制完整目录，避免覆盖工作文件。

## 当前流程

1. 将完整产物目录复制到一个测试目录，保持相对路径。
2. 手动用目标浏览器打开 `maps/minimal.html`。
3. 点击左侧“打开其他图”，选择刚才的 HTML 文件。直接打开页面不会自动授予文件句柄；只有选择完成后才能保存和监测。
4. 点击节点编辑标题和卡片；右上圆形按钮展开笔记。编辑只发生在内存。
5. 点击“保存”或 Ctrl+S / Cmd+S，按浏览器提示授权。写入流关闭后销毁并重建整个编辑会话，通过当前已授权文件句柄重新读取磁盘内容。
6. 页面保留未保存输入时，从文件系统修改图的源文本。文件观察器和 500ms 轮询检测变化后执行同一强制刷新，丢弃未保存输入、历史、焦点与视野；仅保留文件访问能力，不保留旧图数据。轮询会受宿主后台节流影响，焦点恢复时会额外检查。

自动刷新复用当前页面已授权的文件句柄，不依赖浏览器整页导航后再恢复存储中的句柄。浏览器手动重新导航时，尝试从 IndexedDB 恢复文件句柄；会话索引按入口页面 URL 隔离。浏览器未保留权限时明确报告，需要用户通过“打开其他图”重新选择文件。不保存图内容、草稿、视野或撤销历史；读取失败不伪造空图，写入失败不显示保存成功。保存前检查磁盘变化；不承诺多个写入方之间的原子协调。

`alpha.1` 的真实测试中出现 `getFile` 读取被上下文拒绝的错误。`alpha.2` 据此替换自动刷新的导航方式，并记录失败阶段、原始错误名称及只读权限状态用于诊断。新流程已在上述两个宿主中完成真实保存、改盘自动刷新、草稿丢弃与 Cmd+Z 不恢复旧内容的验证；不据此推断浏览器重启后的授权保留或其他宿主均已兼容。

## 已验证的最小流程

- 以本地 HTML 和相对路径公共包打开，运行依赖与公式字体不要求联网或开发服务器。
- 通过系统文件选择器绑定实际图文件；保存写回该文件，隐藏笔记与资源引用保持。
- Agent 原子替换图文件内容后，页面自动读取新内容并重建编辑会话。
- 未保存草稿被丢弃，Cmd+Z 不能恢复刷新前内容，撤销也不写盘。
- 类型检查、22 项源码/文件会话测试和构建通过；当前构建与实际测试的公共资源哈希一致。

## 尚未完成

- 新图首次选址与相对公共资源引用、跨目录图的资源基址、跨运行版本切换仍待接入。此里程碑仅支持同一运行版本的现有图编辑。
- 选择文件的句柄不提供绝对目录；因此从选择器载入后不会借用旧图路径解析相对图片，暂时显示既定图片失败提示。需要后续目录能力或宿主接入完成路径身份。
- 全部五种形态、拖拽与路径避让、批量操作、完整操作级撤销、查找和导航等完整编辑器能力尚未完成。当前画布只提供最小圆角卡片阅读与文本编辑。
- 浏览器重启后的权限恢复、更多宿主和完整编辑器的性能/交互仍需后续验证。当前本地文件验证采用人工操作和文件系统核验，不宣称已具备全自动原生文件测试。

使用 `npm run validate -- /absolute/path/to/graph.html` 对原始文件做只读检查；它不截断后再宣称合格，也不证明浏览器布局或文件权限可用。
