# MindMap 文件流程原型

资源版本：`{{RELEASE}}`。这是最小文件流程原型，完整图编辑器仍在开发。

## 打开与使用

保留 `maps/` 与 `runtime/` 的相对位置，用浏览器直接打开 [minimal.html](maps/minimal.html)。程序、样式和公式字体随包提供，不需要启动服务器或先联网建立缓存。

1. 页面打开后，点击左侧上方的打开按钮 `▱`，在系统文件窗口中选择要编辑的 HTML 文件。
2. 右上角显示“暂无警告”后，单击卡片编辑标题或正文；圆形展开按钮可显示笔记。
3. 点击左侧下方的保存按钮 `▣`，或按 Ctrl+S / Cmd+S；按浏览器提示允许编辑文件。
4. Agent 或其他工具修改当前图文件后，页面自动重新读取并重建编辑会话。

直接打开页面不会自动授予文件读写和监听权限，需要完成第 1 步。保存写回系统选择器中实际选中的文件；在同页切换图之后，浏览器地址栏仍可能保留最初入口的地址。

编辑先存在内存，只有手动保存才写盘。磁盘变化会丢弃未保存草稿，并清空撤销历史；刷新后不能撤销回此前内容。自动刷新保留当前已授权文件句柄，不依赖整页重新导航。手动重新导航后，若浏览器未保留权限，请再次使用打开按钮选择文件。

## 当前范围

本机 Chrome 和 Codex 已完成人工页面操作与实际磁盘核验：本地打开、授权、保存、Agent 改盘自动更新、草稿丢弃及历史清空。

当前只支持同一运行版本的现有图和最小文本编辑。新图首次选址、跨目录相对图片、跨运行版本切换，以及完整形态、拖拽、批量和查找等能力仍待后续完成。

普通保存保留资源版本；请勿只复制 HTML 而遗漏它引用的公共资源。[资源哈希记录](runtime/{{RELEASE}}/manifest.json)可用于核对程序与样式。
