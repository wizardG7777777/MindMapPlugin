# Skill 状态

上一轮 CLI Skill 已移入[历史归档](../docs/archive/2026-10-09-previous-design/snapshot/skills/mindmap-cli/SKILL.md)。新方向的 Skill 尚未实现；以下提示词要求已在[源文本技术草案](../docs/design/source-text.md#agent-写入限长与检查工具)中记录，待后续 Skill 开发接入。

- [外壳 S1](../docs/design/shell.md#s1-已确定的交付与离线使用)规定图 HTML 只保留源文本、必要文档结构与资源引用。Agent 普通改图直接修改节点、边、正文与布局属性，保留明确版本的相对资源引用；不复制运行库、CSS、字体或用户操作界面进图文件，不改写公共包或静默升级资源版本。外链及正文内嵌图片继续沿用原规则。公共资源尚未实现，不能把文档中的示意路径当作实际存在的运行包。
- S6 明确首版仅使用默认主题，不生成主题选择、切换或偏好存储能力；已有形态、线型和 `default`、`basic` 等样式引用保留，不把节点形状当作多主题。

- 首版不提供按内容场景或关系的自动排版。Agent 指定期望坐标，5%／居中及缺失位置的半径 5 随机值都仅作为候选；实际碰撞由 L4 局部避让修正。后续场景自动排版的阶段原则见[逻辑设计](../docs/design/logic.md#首版手动排版与后续自动排版)。
- 全项目禁止节点叠放；L4 允许必要的局部碰撞避让，不能依靠置顶或层级字段覆盖节点。5% 新建位置、视窗中心和半径 5 的随机位置仅作为候选，实际外框冲突时要寻找最近空位，最终坐标可以调整且不保存 `data-z`。静态字数检查不能证明无碰撞。
- HTML 使用 UTF-8 编码，长度按 Unicode 码点计数，不按 UTF-8 字节数或 UTF-16 长度计数。
- 恢复 HTML 节点与 SVG 连线方案，允许组件生成 SVG，继续保留 `rehype-katex`／KaTeX。拖动节点时关联边必须实时跟随，不能只在松开时更新；HTML 仍保存文本、关系与坐标，不保存派生 SVG 路径或公式预览。该方案尚未实现或完成交互验证。
- 节点间关系统一用有向边表达，不分类边；关系元素不写 `data-type`，不填默认类型，也不通过说明关键词恢复分类。图容器、节点和边均不写 `data-type`；节点用 `round-rect`、`rect`、`diamond`、`parallelogram`、`circle`五种外观类名引用几何形态，全部形态可混用；`round-rect` 为默认圆角矩形，`rect` 为直角矩形，不通过皮肤混淆两者。通用新增操作有焦点时仍自动添加一条默认贝塞尔边，无焦点时不连线；S4 的形状按钮有节点焦点时只换形，不调用新增。
- S4 的手动建边必须先选线工具，仅约束用户页面操作，不要求 Agent 改源文本前操作工具栏，也不取消复制关联边。撤销仅 Ctrl+Z／Cmd+Z，复制和删除仅快捷键，查找仅上／下箭头定位；这些入口均尚未实现，Agent 不将按钮、快捷键状态或查找序列写入图文件。
- A2 的 `bezier`、`orthogonal`、`straight` 是边的路径外观类名，不是业务关系类型；缺省为贝塞尔，复制时保留外观。说明框几何、自动配色不写入源文本，编辑时全文显示不取消 1024 码点上限；直线说明框空间不足时可被节点遮挡，但完整文本仍保存，中心仍在线上；当前不增加搬动节点、改线、引线或置顶方案，不把遮挡当作无效源内容删除。
- A3 的焦点描边、批量节点选集、当前查找标记与说明输入显示状态只属于页面，不写入图文件。边说明仅双击编辑时显示，单击选中、悬停和查找不显示；隐藏不删除正文，仍参与保存、计数和查找，不把隐藏 DOM 当作源文本。
- A1 的形态类名记录收起形状；所有节点展开为圆角矩形只是页面展示，不得将其统一改写为 `round-rect`。展开状态、形状图标与名称不保存；展开中主动换形只更新收起形态。三个源字段仍完整保留，空笔记预览隐藏不等于删除 `div.notes`。
- L8 已排除分区、边界、手绘、线框、模板及表格额外能力，不生成 `group` 节点、成员边或归属字段，也不把批量选集解释成永久分组。图片与表格仅写入三个字段中的 Markdown 源码，不生成字段外 `img`、`table.data`、`data-slot` 或图表配置；时序用有向边及说明表达。L6 已确定统一图模型与形态切换；Markdown 图片与表格属于卡片内容，形态切换保留全部内容，不做类型转换或不兼容删除。
- 每个节点标题、卡片文本分别最多 1024 个码点，笔记最多 32768 个；每条连线说明最多 1024 个码点，只支持纯文本，不解析 Markdown／LaTeX。标题必须非空，连线说明可为空。
- 按 HTML 解码并将 CRLF／CR 统一为 LF 后的源码计数，包含 Markdown、公式、图片地址与内嵌图片编码。
- Agent 写入超限内容后，页面载入会对字段硬截断；提示词应要求 Agent 写入前自行检查长度。
- 页面将无法处理的内容集中警告；用户手动保存时只写出有效数据，异常原文和相关无效连线不保留。合法的隐藏笔记、图片仍保存。
- 逻辑部分规划只读字数检查命令行工具，用于报告原始长度、上限与超出数量。工具尚未实现，当前不提供或宣称存在可执行命令；实现后再补充真实调用方式。

手动交互、校验与工具的职责见[逻辑技术草案](../docs/design/logic.md#技术草案)。工具栏建边、单击选边、双击编辑说明、端点改接和 Delete 对象删除已有设计，但尚未实现；不得写成已经可运行。连接位置按源文本中的 `data-start`、`data-end` 草案保存，起点改接必须移动关系的源列表归属，保持边 ID，不额外复制一条边。

- L7 的视野与查找只属于页面状态：打开或刷新后自动适配全部有效节点；节点坐标独立于当前画布缩放和平移，Agent 不把视野、筛选或命中状态写进源文本。

用户操作撤销已确定为产品要求：主动删除节点及关联边作为一次操作恢复，独立自动操作不可撤销；空标题失焦自动删除不能撤销，也不能借更早的文本编辑恢复节点或关联边。任何刷新清空历史，包括手动保存或 Agent 改盘引发的刷新。该能力尚未实现，不能宣称可用，也不能把它作为 Agent 改盘后的恢复机制。

L3 已确定只提供批量移动、删除和复制：移动保持选中节点间相对位置，删除清理全部关联边，复制包含全部关联边；选中端替换为副本，未选端仍指向原节点，副本节点和边必须使用新 ID。外部入边的副本仍追加到原外部源节点的列表中，不能反向存入副本节点；不自动把外部节点一并复制。每次批量操作整体撤销。以上仍是设计，不能宣称已有可执行命令。

不提供重做，不建立重做命令或恢复已撤销操作的入口。不扩展到批量文字、样式或属性修改。首版暂不支持手工折点或折线形态编辑，也不为未来自动排版预先暴露命令。
