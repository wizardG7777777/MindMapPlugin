- [外壳设计草案](design/shell.md)：产品设计与技术草案分开；S1 确定简洁图 HTML 与本地版本化公共资源，S2 确定新建、同页打开和手动保存且无另存，S3 确定常驻左栏、常驻右上警告栏及按需查找框。S4 确定文件按钮置顶、有节点焦点时形状按钮换形、手动建边先选线、撤销／复制／删除仅快捷键、右上缩放滑块与比例，以及查找仅通过上／下箭头定位；既有自动连线和复制关联边规则保留。S5 暂不展开，S6 仅使用默认主题、不提供主题选择入口。
- [通用图、节点形态与内容场景](design/diagram-types.md)：所有图统一为有向图，节点形态可混用与自由切换，全部内容保留；原图类型和业务节点类型清单取消，当前仅保留 L8 确定的内容范围，不再以旧场景清单扩展功能。
