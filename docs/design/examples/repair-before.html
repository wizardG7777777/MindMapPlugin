包含重复节点、缺失位置与无目标连线的输入

这是故意含有异常的输入样例，不是规范化后的有效文档。topic 出现两次，gone 不存在，leaf 缺少位置。

原点节点

零坐标是有效候选，本例保留原点。
指向 topic 的连线应继续连接第一个同 ID 节点。
  • 保留
  • 取消无目标连线

第一个 topic

保留此节点，不与副本合并。
已有位置先作候选；若发生碰撞则局部避让，不重新随机。
  • 保留原关系

后出现的 topic 副本

此副本及其自身出向连线被删除。
即使副本位置看起来更合适，也不能替换第一个 topic。
  • 不合并到第一个节点
  • 随副本删除

缺失位置的节点

先补齐随机候选，再避让；保留内容和有效关系。
初始候选位于原点半径 5 内，最终避让坐标可以超出该范围。
  • 仍指向第一个 topic
  • 取消无目标连线
