# 逻辑设计草案

更新日期：2026-10-15。

本设计属于[四部分架构](architecture.md)中的逻辑部分，分别记录产品设计与技术草案。通用内容、关系和 HTML 表达以[源文本设计](source-text.md)为依据，节点形态与内容目标见[通用图与内容场景](diagram-types.md)。本轮只记录设计，不代表交互、保存、验证工具或宿主兼容已经实现。

## 产品设计草案

### 职责与范围

逻辑负责执行用户操作、维护内存中的有效文档、生成显示所需的数据，并在手动保存时输出源文本。外观提供样式与尺寸，外壳组织界面、资源和宿主入口，逻辑完成具体行为；这些职责不要求拆成独立服务。

| 功能 | 逻辑负责的内容 | 当前状态 |
| --- | --- | --- |
| 读取与校验 | 识别源文本，按规则处理异常，生成有效数据与诊断 | 通用规则已确定 |
| 内存文档 | 维护内容、关系、非重叠位置及未保存修改，区分编辑草稿与临时展示状态 | 通用原则已确定 |
| 节点编辑 | 新建、删除、文本修改、焦点切换、限长与编辑收尾 | 通用规则已确定 |
| 关系编辑 | 工具栏建边、选中与文字编辑、端点改接、对象删除；不分类边 | L1 已确定，不再设置关系类型入口 |
| 手动排版与避让 | 新建定位、拖拽、位置恢复、局部碰撞避让及连线路径更新，不提供层级调整 | L4 已确定 |
| 内容展示 | 卡片展开与收起，Markdown、公式、图片与表格预览 | L8 已限定内容范围，不增加其他编辑器 |
| 画布交互 | 载入时自动看全图、手动缩放、回原点、按节点／边查找、居中定位与焦点跟随 | L7 已确定，不提供手动显示全部或恢复 100% 入口 |
| 操作撤销 | 按用户操作记录历史，自动操作不作为可撤销项；空标题自动删除不可恢复，刷新清空历史；不提供重做 | L2 已确定 |
| 批量操作与复制 | 只提供批量移动、批量删除、批量复制；复制全部关联边 | L3 已确定 |
| 保存与刷新 | 编辑收尾、有效数据序列化、文件写入接入及重新载入 | 产品原则已确定，宿主机制待验证 |
| Agent 辅助验证 | 共享校验规则，规划只读字数检查入口 | 职责已规划，工具尚未实现 |

### 首版手动排版与后续自动排版

已确定的阶段原则：**第一个版本不做图的自动排版。先把手动排版与编辑流程做完整、做到实际可用，再针对每一个具体布局场景逐项设计自动排版，不恢复图类型字段。**

首版不提供按内容场景或关系结构组织节点的全图、局部自动排版。用户通过拖拽摆放，Agent 在 HTML 源文本中指定坐标；场景名称和关系本身不推导新的位置。L4 新增的局部碰撞避让属于必须满足的几何约束：原位置没有碰撞时保留，发生碰撞时移到最近可用位置，允许局部移动其他节点，但不按关系重新组织整张图。

这是一项分阶段的范围决定，不表示流程图、复杂有向图等无法自动排版，也不是永久取消所有图的自动排版。未来只在手动流程验证可用后，针对某一个布局场景讨论触发方式、作用范围、位置保留规则和适用条件，不要求首版预先提供统一算法、布局引擎或自动回退策略。

首版仍保留以下必要计算：

| 计算 | 保留的行为 | 与自动排版的边界 |
| --- | --- | --- |
| 新建定位 | 按焦点、5% 间距或视窗中心得到候选位置，再避让 | 无碰撞时保留候选；有碰撞时以不重叠为准，不补建或改写边 |
| 缺失坐标补齐 | 在图原点半径 5 内随机生成候选，再避让 | 最终位置可以超出半径 5，不重新随机直到碰巧无碰撞 |
| 局部碰撞避让 | 移动目标或受影响邻居到最近空位，保持可用位置不变 | 不按布局场景、边或节点数量重排整张图，不自动收拢空隙 |
| 连线路径 | 根据端点位置和卡片尺寸计算显示路径 | 不为减少交叉而移动节点或改变关系 |
| 卡片内部排版 | 按标题、卡片内容、笔记的规则显示与滚动 | 外框尺寸改变时检查碰撞；仅在有冲突时局部避让 |
| Markdown 表格预览 | 呈现源码中的行、列与单元格 | 仅是卡片内部预览，不新增图节点、表格运算或画布自动排版 |

后续按布局场景增加自动排版时，仍需保留通用有向关系和有效内容保存原则；算法适用性不能成为源文件合法性的前提。

### 已确定的编辑与关系规则

以下规则承接源文本设计，不在逻辑部分重新作为待讨论问题。

| 操作或状态 | 已确认的结果 |
| --- | --- |
| 普通新建节点 | 立即创建，默认标题为“新节点”，卡片文本和笔记可为空，自动获得编辑焦点；复制按 L3 保留原内容 |
| 形状按钮分发 | 有节点编辑焦点时修改其形态，无节点焦点时新增；批量选集不等于节点编辑焦点，不执行批量换形 |
| 通用新增操作有原焦点 | 在原节点右方或下方定位，边缘间距为创建瞬间视窗对应宽高的 5%；自动建立原节点到新节点的默认贝塞尔边；形状按钮的换形分支不调用此操作 |
| 无原焦点时新建 | 新卡片中心位于创建瞬间的视窗中心，不连接其他节点 |
| 通用新增操作的原节点收尾删除 | 新节点仍创建，位置使用已捕获的原节点外框；不保留以已删除节点为端点的连线。换形目标收尾删除则终止换形，不补建节点 |
| 点击与焦点 | 图中至多一个节点或边获得对象编辑焦点；普通模式单击节点即编辑，单击边选中、双击边编辑说明；切换对象先收尾原对象，内部字段切换保持焦点 |
| 编辑与预览 | 节点有焦点时显示当前可见字段的纯文本源码，无焦点时预览；获得焦点不自动展开笔记。边说明仅双击编辑时显示，退出编辑隐藏 |
| 空标题草稿收尾 | 先在标题为空、卡片非空时交换两者；标题仍为空则删除节点，笔记非空不构成例外；只含空白也视为空 |
| 单节点拖拽 | 请求改变目标坐标，有碰撞时按 L4 局部避让；批量移动保持选集内部相对位置，边和源码顺序均不变 |
| 禁止叠放 | 不允许节点部分或完全重叠，也不提供置顶、置底或逐层调整；有碰撞先避让，不靠遮挡顺序解决 |
| 删除节点 | 主动删除和空标题自动删除共用规则：删除目标及其全部入边、出边，其余内容保持原样；不级联、不重接、不重排 |
| 关系结构 | 允许多个入边、多个出边、平行关系、回路、自环、孤立节点和空图；树是特例，不施加无环、单父或根数量限制 |
| 关系表达 | 节点不预设相互关系，由实际存在的有向边建立连接；边无内置类型，方向和可选说明表达联系，说明为空不删除边 |

边获得焦点时没有焦点节点；此时新建节点按无焦点节点规则居中且不连线，不使用上次选中过的节点代替。节点拖拽只修改坐标；以下连线端点拖拽是独立的关系操作，不移动节点。

### L1 已确定的连线交互

页面设置工具栏，包含节点入口和连线入口。节点入口按 L6 提供五种启动形态，按 S4 在有节点焦点时换形、无节点焦点时新增。用户手动创建边必须先选择工具栏中的线工具；默认贝塞尔，也可选择直角折线或直线，进入建边模式后依次点击起点和终点。普通节点点击本身不开始建边。

不再区分基础关系类型，也不要求建边时选择业务类别；A2 提供的三种选项仅是路径外观。工具栏建边和有焦点节点时的新建连线都生成同一种未分类的有向边，初始说明为空；不是通过默认类型值代替被删除的类型清单。用户可以用说明描述用途，程序不解析其中的关键词来恢复包含、流程或依赖等分类。图与节点也不设置业务类型；节点形态不自动推导节点之间的关系。

选线要求只约束用户手动建边，不取消通用新增操作的自动连线或 L3 复制关联边。自动新增且未指定外观的边使用贝塞尔；复制保留原边的既有外观，缺省才使用贝塞尔。Agent 直接编辑源文本、撤销恢复边和端点改接不需要重新选择建边工具。

点击位置可以在节点内部，但实际连接点必须位于节点可见轮廓的边缘，并且是距离该次鼠标点击最近的边缘点。起点、终点分别计算，不能一律改成固定的边中点，也不能忽略点击位置只选择两个节点之间最短的连接方向。

| 操作 | 已确认结果 |
| --- | --- |
| 点击连线按钮，再点击节点 A、节点 B | 以 A 为起点、B 为终点；分别按两次点击确定最近的边缘连接点，完成后才形成一条有效边 |
| 单击连线 | 选中该边并获得对象编辑焦点，以粗描边表示，可直接按 Delete 删除；说明框隐藏 |
| 双击连线 | 在选中该边的基础上显示说明框并进入文字编辑；边仍是当前焦点对象，退出编辑后隐藏说明框 |
| 拖动连线起点到另一个节点 | 修改这条边的起点节点，按落点确定新节点上最近的边缘连接点；终点不变 |
| 拖动连线终点到另一个节点 | 修改这条边的终点节点，按落点确定新节点上最近的边缘连接点；起点不变 |
| 编辑说明 | 仍为最多 1024 个码点的纯文本；允许空说明，清空说明不删除边 |
| 路径外观与折点 | 创建时可选贝塞尔曲线、直角折线或直线；首版仍不提供手动折点或说明框位置拖拽，实际路径由逻辑生成 |

端点改接保持原边的标识和说明，只更新指定端及其连接点；不创建替代边，不移动端点节点。自环、平行边和有向回路继续按既定关系模型允许，不能因采用依次点击或端点拖拽而额外禁止。

连接点是用户摆放结果的一部分，随手动保存保留；节点移动、卡片展开收起后仍贴合对应节点的边缘。路径的中间形状、选中状态和说明输入状态由逻辑维护，不作为用户手调折点保存。不设置业务关系类型选择或修改入口，也不自行增加说明文字位置的拖拽入口。L1 的通用有向边与交互规则据此结案。

### 对象焦点与 Delete 删除

对象编辑焦点统一指向一个节点、一条边，或为空。单击节点进入节点文本编辑；单击边只选中边，双击再进入该边的说明编辑。边的选中与说明编辑是同一焦点对象的两种状态，不同时保留另一个节点的编辑焦点。

切换对象时，节点执行已有的失焦交换或删除规则，边接纳合法说明并退出文字编辑；空说明不触发删除。点击工具栏或画布空白时取消原对象焦点。连线模式的节点点击用于取起点与终点，不同时进入节点正文编辑。

**节点或边获得对象编辑焦点后，Delete 删除整个对象，即使文字光标位于该对象的文本控件内。** 该按键不再执行字符删除或仅删除选中文字：

- 节点有焦点：删除该节点及所有入边、出边，其他节点和关系保持不变。
- 边有焦点：单击选中后即可删除整条边，无需双击；端点节点、其他边及节点位置保持不变。
- 没有对象焦点但存在批量节点选集：按 L3 批量删除；对象焦点与批量选集不同时激活。
- 既没有对象焦点也没有批量选集：不删除上次选中过的节点或边。

Delete 是主动对象删除，直接执行删除命令，不先把它解释为清空标题再交换正文。文字仍可通过退格、剪切、选区替换等文本操作修改；这些操作继续遵守输入与失焦规则。删除只修改内存，手动保存才写盘；作为用户操作可以撤销，主动删除节点时连同关联边一起恢复。

### L2 已确定的撤销原则

**提供操作级撤销，用户操作可以撤销，自动执行的操作不能撤销。** 判定依据是用户执行的完整动作，不是底层有多少函数调用或页面事件；不能只提供文本框内部撤销来代替图上的操作撤销。

**只提供撤销，不提供重做。** 被撤销的操作不能通过重做按钮、快捷键或其他应用入口恢复；撤销动作本身也不作为可再次撤销的普通编辑记录。继续撤销只回退更早的有效用户操作，不在撤销和重做之间切换。

S4 将用户撤销入口限定为 Ctrl+Z 或 Cmd+Z，不提供撤销按钮或菜单。复制和删除同样只提供快捷键，Delete 的对象级优先级保持，复制的技术默认组合见[外壳入口接入](shell.md#入口分发快捷键与查找导航)。

用户动作自身包含的必要结果作为同一次操作处理。已经明确：用户主动删除节点时，节点及其全部关联边属于一次完整删除；撤销时一并恢复，不把关联边清理单独视为不可撤销的自动任务。新建节点时按既定规则附带的连线、默认内容与聚焦同样属于该次新建的完整结果，不拆成多次撤销。空标题失焦自动删除明确归为不可撤销的自动操作，不因其前面发生过用户文本编辑而并入可恢复的用户动作。

| 操作来源或场景 | 撤销原则 |
| --- | --- |
| 用户修改图内容 | 新建、主动删除、文字编辑、拖拽、建边、端点改接以及已支持的其他用户编辑均可撤销；恢复该次操作影响的合法内容和关系 |
| 用户改变页面展示 | 主动选择、卡片展开收起、平移缩放和滚动等实际改变页面状态的操作也属于用户操作；恢复页面状态，不因此增加源文本持久化字段 |
| 用户主动删除节点 | 一次恢复节点、关联边、内容、连接位置及源顺序；恢复位置须满足当前几何条件，不恢复层叠字段 |
| 用户主动删除边 | 只恢复被删除的边，端点节点不因撤销而被替换或重复创建 |
| 空标题失焦自动删除 | 不可撤销；删除的节点及随之清理的关联边均不恢复，也不能通过撤销此前的清空、编辑、选择或移动间接恢复 |
| 载入时自动处理 | 去重、无目标边清理、缺失坐标候选、超限截断、无效内容排除与局部避让不入用户历史 |
| 自动显示更新 | 连线路径、尺寸测量、Markdown 与公式预览、图片加载结果等派生更新不生成独立撤销项；撤销用户动作后按当前有效数据重新计算 |
| Agent 或其他工具改盘 | 不作为页面用户操作记录；按既定规则触发刷新并丢弃未保存编辑 |

**撤销历史只存在于本次页面加载后的内存会话中，任何刷新都会清空，包括用户手动保存引发的刷新。** 保存后不能跨刷新撤销之前的操作；页面撤销也不承担硬盘文件版本回滚。保存失败且没有发生磁盘变更时，不仅因尝试保存而清空历史。

撤销本身只修改内存中的文档或页面状态，仍需手动保存才写回硬盘。恢复结果遵守既定有效性约束，不利用撤销恢复已被加载处理排除的错误内容。主动删除的合法内容可以临时保留在撤销记录中，这不属于异常原文保存或磁盘草稿恢复。

节点仍存在、尚未触发空标题自动删除时，可以正常撤销文本编辑；一旦因标题与卡片文本都为空而在收尾时被自动删除，节点和当次清除的关联边不再通过历史恢复。主动删除和自动删除继续共用相同的数据清理规则，但必须保留不同的操作来源；删除结果相同不表示撤销资格相同。

自动删除的结果优先于历史回放。旧记录不能重新创建该节点、恢复已清除的边或恢复指向它的编辑焦点；与它无关的有效用户操作仍可撤销，不因为这次自动删除而清空全部历史。L2 的撤销范围、自动删除边界、刷新清空历史及不提供重做的规则据此结案。

### L3 已确定的批量操作

**只支持批量移动、批量删除和批量复制，不提供批量修改文字、形态、样式或其他属性。** 批量操作的目标是一组用户选中的节点；边根据移动、删除或复制规则随之处理，不另外扩展成批量编辑边的功能。

批量节点选集与单个对象的编辑焦点分开。鼠标拖出选框只选择节点，边不能被框选；全部选中节点复用统一焦点粗描边。进入批量选择时先收尾原编辑对象，再清除单对象焦点；多个选中节点不会同时进入正文编辑。普通单击只命中一个节点，回到单对象编辑时退出批量选择。批量选集不表示分组归属，不写入源文本，刷新后清空。

| 批量操作 | 已确认结果 |
| --- | --- |
| 移动 | 所有选中节点应用相同图坐标位移，彼此相对位置保持不变；发生碰撞时整组选集避让，也允许局部移动碰撞邻居。边、内容和源码顺序不变，未受碰撞影响的节点不动 |
| 删除 | 对选中节点应用既定单节点删除规则：删除这些节点及所有以它们为起点或终点的边；同一边只清理一次，未选中节点与其他边保留，不级联、不重接、不重排 |
| 复制 | 为每个选中节点创建独立副本，保留其文本、属性、形态、样式和 Markdown 内容；复制所有关联边，包括连接到未选中节点的入边和出边；原有节点与边保留 |

复制选中节点 A、B，未选中 C 时，关系按以下方式复制：

| 原有边 | 新增副本边 | 说明 |
| --- | --- | --- |
| A → B | A′ → B′ | 两端都在选集中，全部改为对应副本，不生成额外的 A → B′ 或 A′ → B |
| A → C | A′ → C | 复制出向外部关系，C 不复制 |
| C → A | C → A′ | 复制入向外部关系，C 不复制；在原 C 的出向列表中追加这条新边 |
| A → A | A′ → A′ | 自环仍为副本自身的自环 |
| 同端点的多条边或回路 | 分别复制对应的边与方向 | 按原边标识逐条处理，不合并平行边，不拆开回路 |
| C → D，C、D 均未选中 | 不新增 | 不复制与选集无关的关系，也不沿关系递归复制更多节点 |

副本节点和副本边均使用新标识，内容不与原对象共享可变状态；边的说明与两端连接位置保留，不引入类型字段。原节点内容和原有边不改写；副本整组寻找空位，只有必要的局部避让可以调整受影响节点坐标。新增外部入边只是在未选中源节点的列表中追加，不替换已有边。

复制与普通新建是不同命令：复制保留原标题，不改成“新节点”，不额外建立原编辑焦点到副本的边。副本之间保留原来的相对摆放，整组移到最近可用位置，不再原位叠放。每次批量操作及其必要局部避让整体撤销，不提供重做；自动删除的不可恢复边界继续适用。

### L4 已确定的禁止叠放与局部避让

**整个项目完全禁止节点叠放，不提供置顶、置底、上移一层或下移一层。** 用户与 Agent 应平铺安排节点；节点形态、内容、编辑焦点或卡片展开状态均不构成叠放例外。节点的绘制层次只属于渲染内部实现，不再作为可编辑或持久化的文档数据。

采用自动避让：当候选位置或新尺寸会与其他节点重叠时，将目标或受影响邻居移动到最近空位。允许局部移动其他节点，不进行按关系或内容场景的整图自动排版；没有碰撞的节点尽量保持原位，不因删除、收起后腾出空间而自动收拢整个图。

| 场景 | 已确认的处理方向 |
| --- | --- |
| 普通新建 | 焦点右方／下方的 5% 间距或视窗中心仍是初始候选；若冲突，再寻找最近空位 |
| 单节点拖动 | 鼠标指定位置是候选；保持展示与提交结果无重叠，必要时调整目标或碰撞邻居，不改写边 |
| 批量移动与复制 | 将选集或副本作为刚性整体平移，保持组内相对位置；不能把成员分别挤散，不能继续原位重叠 |
| 打开重叠文件 | 在内存中先测量并局部避让，再显示可编辑图；不因重叠删除节点、丢弃内容或要求用户修好才可保存 |
| 缺少坐标 | 原点半径 5 的随机结果仅作为候选，随后避让；最终有效坐标不再受半径 5 限制 |
| 卡片展开、文字或样式尺寸变化、图片加载 | 按实际新外框检测碰撞，允许局部移动其他节点；标题固定区、滚动与可见性规则照常执行 |
| 保存与重新打开 | 手动保存避让后的坐标；重开若当前尺寸下没有碰撞则保持坐标，有碰撞仍须局部修正，不恢复重叠画面 |

用户拖动、展开、复制等操作导致的避让属于该次用户操作的完整结果，记录所有连带移动的节点，撤销时一起恢复。载入、图片异步加载等独立触发的避让不进入用户历史，不可单独撤销；若后续独立自动变化使旧记录不能安全回退，沿用 L2 的历史有效性处理，不借旧快照倒退自动结果。

所有避让先作用于内存，仍只在手动保存时写盘；独立自动避让若改变坐标，也属于待保存的位置变化。此规则取代此前“允许重叠”“卡片变化绝不移动其他节点”“复制原位叠放”和“保存恢复叠放顺序”等规定，首版不做图的自动排版原则继续保留。

### 已确定的文本与展示规则

| 内容 | 规则 |
| --- | --- |
| 长度 | 标题、卡片文本和连线说明各最多 1024 个 Unicode 码点，笔记最多 32768 个；文件编码为 UTF-8，不能按字节或 UTF-16 长度代替计数 |
| 输入 | 超限普通输入拒绝，超限粘贴按剩余容量截断本次粘贴；既有未选中文本保留，不增加超限禁止保存流程 |
| Agent 写入 | 载入时对超长字段按上限硬截断，不做语义补全或 Markdown 边界补全；截断结果先进入内存 |
| 节点文本 | 三个字段统一支持 Markdown、内联与块级公式；源文本保存原始标记，预览不能覆盖源码 |
| 连线说明 | 仅纯文本，不解析 Markdown 或 LaTeX；可为空。仅双击编辑时显示所属说明框，退出编辑隐藏；显示时全文扩张，中心在线上且通常避让节点与其他可见说明框，直线空间不足时可以被节点遮挡。隐藏不影响保存、计数或查找 |
| 卡片默认状态 | 新建、重新打开或刷新时使用各自收起形状；展开与内部滚动状态不保存 |
| 展开 | 长按 1 秒或点击右上方圆形按钮；五种形态统一为一档固定圆角矩形，标题置顶并标识收起形状，卡片内容与笔记共同滚动 |
| 收起时可见性 | 标题文字和卡片内容可滚动查看；标题图片不渲染，卡片内容中的图片完整渲染，笔记全部隐藏 |
| 展开时可见性 | 按标题、卡片内容、笔记顺序显示；空笔记预览省略分区，展开编辑仍可输入；“可见”包括滚动访问 |
| 尺寸变化 | 更新外框测量并执行必要的局部避让，再更新相关连线路径；无碰撞时保持坐标，不提供层级调整 |
| 图片失败 | 原位置显示常量警告，保留引用和正文，不阻止保存；提示本身不是内容修改，若外框变化触发避让则只记录相应坐标变化 |
| 折叠范围 | 只保留卡片自身收起与展开，不提供子树或分组折叠，不沿关系隐藏其他节点 |

完整的字段计数、图片警告文字、内容归属与展示要求见[源文本产品设计](source-text.md#产品设计草案)。Markdown 图片与表格仍归属于标题、卡片内容或笔记之一，不绕过通用可见性与标题规则。

### 已确定的异常处理与保存规则

载入时先去重、清理无目标边、截断并排除无效内容，为缺失坐标生成候选，再测量有效节点并局部避让。重叠只修正位置，不删除有效内容或边，不补齐层叠字段。

无法自动处理的内容在右上方警告栏集中警告，有效部分仍可显示、编辑和保存。无效节点及其关联连线不进入有效模型；无法解释的可选内容排除，但不阻断同一节点的其他有效内容。若保留了有效图容器但所有节点均无效，允许保存为空图；文件无法读取或图结构完全不可识别时报告原因，不猜测缺失节点或关系。

用户编辑与自动分类处理的结果先留在内存，只有手动保存才写回硬盘。保存从当前有效模型生成完整 HTML，只输出有效内容；合法但暂时隐藏的笔记与媒体也完整保存。异常原文、警告文字和无效连线不输出，不增加原文保留、局部补丁或错误内容恢复机制。

Agent 直接编辑硬盘 HTML；任何磁盘变化强制刷新，包括手动保存。重开时卡片收起，恢复坐标并按当前外框避让；修正只在内存中等待保存，不恢复叠放或旧历史。图片失败只影响预览，合法引用保留；异步资源若改变外框，另行检查碰撞。

### L6 已确定的通用图与节点形态

L6 按以下规则结案，取消原先的图类型、业务节点类型和不兼容转换设计。

| 原议题 | 已确认的产品规则 |
| --- | --- |
| L6.1 新建图 | 所有新建图都是同一种通用有向图，不要求选择思维导图、流程图等类型；按外壳 S2 从一个默认标题“新节点”的节点开始，用户随后自行组织内容、位置和有向边 |
| L6.2 新建节点 | 工具栏提供节点入口，启动形态为圆角矩形、直角矩形、菱形、平行四边形和圆形；后续再按需要扩充可用形态 |
| L6.3 混用 | 所有可用节点形态可以在同一张图中混用，不存在按布局场景限制节点的允许组合表 |
| L6.4 切换 | 已有节点可自由切换几何形态，卡片的全部内容保持不变；整张图没有业务类型，因此也没有图类型转换 |
| L6.5 内容兼容 | 所有形态使用统一的内容模型，不区分图片节点、图表节点等内容互斥的业务类别；从设计上避免形态与内容不兼容，不提供丢弃内容的形态转换流程 |

工具栏形状按钮按 S4 复用新增与换形：有单节点编辑焦点时只把该节点改为所选形态，无节点焦点时才创建对应形态的节点。一次点击不同时新增与换形，批量选集不产生批量换形。启动素材与外观说明见[外观草案](appearance.md#已确定的启动形态与工具栏)。

通用新增操作仍立即创建标题为“新节点”的卡片，自动聚焦，并按原焦点决定自动贝塞尔边、候选位置和局部避让；形状按钮在有节点焦点时执行换形，不调用此新增操作。不同形态只影响外观与几何计算，不改变文本规则、卡片展开方式、既有边及保存方式。

新建整张图与向当前图新增节点分开分发。S2 的新图初始化复用默认节点内容，卡片文本和笔记为空、没有边；不继承旧图焦点或建立跨文件连线。初始化一个节点不改变允许空图的规则，打开已有空图或删除最后一个节点时不补回初始节点。

切换形态保持节点 ID、标题、卡片文本、笔记文本、全部 Markdown 源码与资源引用、属性和关联边。Markdown 图片与表格是卡片中的内容，可以共存；它们不决定卡片必须采用何种形态。所有形态都需支持完整内容的访问，不能以内容过长或轮廓不同为理由删减有效数据。

形态记录表示收起形状。展开一律显示为圆角矩形，形状图标与名称仅作识别提示；展开时切换形态更新收起形状及标识，不改变展开外框。只有当前可见外框确实改变时，才按 L4 测量并局部避让，使连接点贴合新轮廓。用户的形态切换与同步产生的邻居位移作为一次完整操作撤销。L3 仍只支持批量移动、删除和复制，不因允许单节点切换就增加批量形态操作。

### L7 已确定的画布浏览与对象定位

| 原议题 | 已确认的产品规则 |
| --- | --- |
| L7.1 初始视野 | 每次打开或刷新后，自动调整平移与缩放，使所有有效节点都在视窗内；用户随后可以自行调整缩放比例 |
| L7.2 浏览入口 | 缩放滑块与比例显示、回到原点、查找入口都放在右上角，与警告栏同区；不提供手动“显示全部”或“恢复 100%”选项 |
| L7.3 查找 | 提供文本查找，仅设置“节点”“边”两种对象筛选条件；不选筛选条件时查找两类对象中的全部文本 |
| L7.4 定位 | 仅通过查找框的上／下箭头定位上一／下一命中对象，不提供可点击结果列表；节点中心对准视窗中心，只突出当前对象，不自动选中、编辑、展开卡片或显示边说明框 |
| L7.5 编辑跟随 | 获得编辑焦点的对象必须保持在视野内；必要时自动移动视窗中心，使当前操作目标持续可见，不能因新建落点、局部避让或尺寸变化而丢到视窗外 |

“编辑焦点对象”沿用已有定义，包括节点和边。节点筛选覆盖标题、卡片文本、笔记中的全部文本，包括 Markdown 图片与表格源码；边筛选覆盖连线说明。不筛选时覆盖上述全部文本，包括当前收起而不可见的内容，不只检索已经渲染的 DOM；不新增按字段、形态或业务类型筛选。

查找、缩放、回原点和焦点跟随只改变浏览状态，不改写节点坐标、内容或关系，不触发整图自动排版。回到原点将图坐标原点移到视窗中心，保留用户当前缩放比例。节点居中定位同样保留当前比例，不恢复到 100%。

A4 已确定画布内所有元素等比缩放，不保证最小可辨识尺寸；包括文字、连线、箭头、说明框、焦点描边及图内操作控件。不因缩小而隐藏正文、改变展开状态或单独放大控件；焦点跟随只平移使操作区域可见，不为可读性自动提高比例。浅灰点阵属于默认外观，不产生吸附、坐标取整或布局行为。

视野、查找词、筛选条件与命中状态只存在于内存，不写入图文件。任何刷新仍清空旧状态和撤销历史，卡片重新收起，再按当前有效节点重新计算初始视野；包括手动保存或 Agent 修改文件引发的刷新。具体边定位、查找匹配与焦点事件接入由技术草案补齐。

### L8 已确定的内容范围

| 编号 | 当前产品决定 |
| --- | --- |
| L8.1 图片 | 仅使用 Markdown 图片语法，不提供非 Markdown 的图片语法或额外操作能力 |
| L8.2 表格 | 仅支持 Markdown 表格语法，不提供非 Markdown 表格语法或编辑能力 |
| L8.3 平面单元表 | 用户已澄清为“Excel 表”，记录为 Excel 式行列表格；仍遵守仅 Markdown 表格与不增加表格额外能力的限制 |
| L8.4 手绘 | 不支持任何手绘内容或笔画编辑 |
| L8.5 表格扩展 | 不提供基于表格的额外能力，也不设置成员表、字段表等专用编辑器 |
| L8.6 时序 | 当前完全通过有向边及既定说明表达，后续再按需要优化，不引入专门消息或时间数据结构 |
| L8.7 分区与边界 | 不考虑分区、泳道区域、系统边界等展示能力；继续单纯执行禁止节点叠放 |
| L8.8 线框与模板 | 不提供线框或内容模板能力 |

“Excel 式”说明行列单元格的呈现形式，不扩展成 Excel 文件读写、公式计算或独立电子表格编辑器。当前编辑方式仍是节点聚焦时修改 Markdown 源码，退出焦点后预览；图片链接、内嵌引用、固定失败提示、三个字段的长度与区域可见性规则继续适用。既定 LaTeX 数学公式是文本预览能力，不是表格计算能力。

原草案中的独立 HTML 图片、结构化表格、数据图表系列与配置、成员表、笔画、分区和模板设想退出当前范围；不把它们保留为本轮必做项或待讨论前置条件。时序仍使用现有有向边，不改变边说明仅纯文本的规则。

### A3 交互状态与外观联动

节点编辑焦点、批量选中节点、选中边和当前查找定位对象使用统一粗描边，默认背景下为蓝色。逻辑继续区分这些状态的操作含义：批量选集不同时编辑文字，查找标记不成为 Delete 目标，单击选中边不打开说明输入。

只在双击进入边说明编辑后显示说明框；退出编辑先接纳有效文字，再隐藏。隐藏框不参与避让，但说明继续参与保存、限长与查找。没有鼠标悬停反馈，也不增加操作过程提示、候选目标高亮或避让闪烁；实际几何更新、框选矩形与选中边端点控件保留。具体外观见[A3 交互状态](appearance.md#a3-已确定的交互状态)。

### 未确定的产品问题

L1–L4、L6、L7、L8 已按本轮决定记录；L5 独立议题已撤掉，相关分区与边界能力也已排除。当前 L 编号清单没有剩余待定项，首版产品设计基线已齐备。具体技术接入与验证继续按草案推进，不代表运行实现或宿主验证已经完成。

#### 重新分析后的讨论边界

- **边不再分类。** L1 只维护有向连接、可选说明与连接位置，不再讨论关系类型设置；建边、选点、端点改接、文字编辑和删除已确定。说明是用户内容，不是隐藏的类型编码，用户也不手调折线。
- **不再设计层级控制。** L4 已确定禁止叠放并自动局部避让；L7 已确定视野、查找和定位，不增加置顶或穿透选择入口。
- **形态与内容分开。** L6 已确定统一有向图与几何形态切换，不设置图类型或业务节点类型。L8 将图片与表格限定为 Markdown 内容，不设置不兼容的类型转换。
- **不增加分区与模板。** L8 已排除分区、边界、线框、模板和手绘能力；批量选集仍是临时状态，不引入永久分组、归属或包含规则。
- **已定与候选能力分开。** L2 只提供操作撤销，L3 只支持批量移动、删除和复制，L4 不提供层级命令；不能将批量能力扩展为批量样式或属性编辑。
- **通用操作先于内容扩展。** L1–L4、L6–L8 已记录，按已确认范围推进。自动排版按已定阶段延期，局部避让不恢复自动排版需求。

外壳负责这些能力的界面组织，逻辑负责执行已确认的操作结果。具体按钮位置、快捷键、手势默认值、命中容差、路径算法、字段编码和库版本由开发方补齐，不逐项列为产品问题。复制范围已确定，分配新 ID、端点映射和更新派生索引由技术草案落实。外观样式集合仍归外观设计，不混入本清单。

### 阶段安排

首版先完成手动创作、文本与卡片交互、无重叠位置保存、撤销、三种批量操作、局部避让及宿主读写刷新验证。L1–L4、L6–L8 已定，图片与表格沿用 Markdown 编辑和预览；不纳入已排除的手绘、分区、线框或模板，整图自动排版仍延期。

手动排版达到完整、稳定、实际可用之后，才开始具体布局场景的自动排版设计，不恢复文档类型字段。该条件需要真实交互与保存往返的验证，不能用静态 HTML 样例或文档检查代替。预期规模保持 10–200 个节点，1000 个及以上不纳入当前支持目标；不新增节点数硬上限或提前建立大图优化框架。

## 技术草案

### 实现约束与职责衔接

运行逻辑与验证工具均使用 TypeScript，浏览器执行编译后的 JavaScript。以下为实现方向，尚未编写代码；模块如何拆分不增加新的顶层架构部分。

复用已确定的 React 文本预览环境、原生多行文本控件与 Markdown 解析方案；公式继续由 `rehype-katex`／KaTeX 渲染，允许其局部 SVG 输出；画布交互和连线路径依赖由开发方另行选型，图片与表格复用已定 Markdown 预览。首版不引入自动排版引擎，不建立预留的布局任务系统，也不因为渲染依赖具备自动布局能力而默认开启。

逻辑接收外壳传入的操作、资源基址和宿主文件事件，返回有效文档变化、展示数据和诊断；外壳负责控件入口、右上方警告栏与文件能力接入。CSS 提供样式和尺寸，逻辑测量变化并更新受影响的显示。

按[外壳 S1](shell.md#s1-已确定的交付与离线使用)，逻辑编译产物、外观、外壳及运行依赖统一放在按版本管理的本地公共资源中；图 HTML 只保存源文本和必要引用。启动直接读取当前图文档，普通内容编辑不修改公共程序，也不要求重新构建资源。资源路径相对于图文件，正文图片仍使用原图基址，不混用公共程序的所在目录。

### 运行时绘制与实时跟随

采用 HTML 节点内容与 SVG 连线，允许应用和依赖在运行时生成 SVG；公式继续使用 KaTeX。节点正文与输入控件保持普通 HTML，SVG 负责连线路径及需要的图形轮廓。具体依赖与版本仍由开发方落实，本轮不实施。

**用户拖动节点时，关联连线必须在拖动过程中实时跟随，不能只在鼠标松开后更新。** 单节点和批量移动都适用；局部避让同步移动的邻居，其关联边也须按同一几何状态更新。既定自环、平行边、多入边与多出边均完整保留，不通过隐藏连线来假装跟随流畅。

技术接入按如下顺序处理每轮显示更新：

1. 收集本轮指针变化，计算节点候选位置及必要的局部避让，并处理当前视野变换。
2. 以同一批最终节点坐标、轮廓与尺寸计算受影响边的连接点、路径和说明位置。
3. 可用 `requestAnimationFrame` 合并本轮高频输入，在下一次可见画面中同步更新 HTML 节点位置与 SVG 路径；不等待拖拽结束，不重建整个文档或重复更新无关节点。
4. 松开或取消拖动时按既定规则收尾；取消需要一起恢复该手势的节点位置、连线和同步视野变化。一次拖拽仍是一次可撤销用户操作，不为每个显示帧增加历史项。

实时跟随不意味着自动修改业务关系或立即写盘。连线几何是派生显示，节点坐标变化按既有内存编辑和手动保存原则处理；绘图库内部状态、SVG 路径及公式预览不作为源文本回写。

卡片内部的公式与图中的连线分开更新。Markdown／LaTeX 内容及排版条件没有变化时，现有 KaTeX 结果跟随卡片容器移动，无需每帧重新运行公式排版。改变公式内容或影响排版的样式时才更新相应预览。公共样式更新影响节点轮廓或外框时，沿用测量、连接点投影与局部避让规则；首版只加载默认主题，不提供运行时主题切换。

上述更新方式是技术草案，尚未证明目标宿主中的实际流畅度。验收必须在持续按住鼠标时检查中间画面与路径，并按预期的 10–200 个节点场景验证，而不是只比较拖动结束前后的静态截图。

### 内存状态划分

| 状态 | 包含内容 | 是否写入源文本 |
| --- | --- | --- |
| 有效文档 | 图信息、节点内容、收起形态与样式引用、边和连接位置、最终坐标及源顺序 | 手动保存时写入，不保存叠放字段 |
| 编辑草稿 | 当前控件输入、选区、输入法组合状态、暂时为空的标题草稿 | 先按规则接纳或收尾，不能直接序列化无效草稿 |
| 页面状态 | 单对象焦点或批量节点选集、边说明输入状态、建边与拖拽草稿、卡片展开、内部滚动、派生形状标识、画布变换、查找词、对象筛选、命中状态和诊断 | 不写入；刷新后重新初始化 |
| 用户操作历史 | 当前加载会话中的用户动作、受影响的文档或页面状态，以及撤销所需的合法原内容 | 不写入 HTML 或其他持久存储；任何刷新清空 |
| 派生数据 | 节点索引、入边索引、实际尺寸、屏幕位置、连线路径、查找索引和预览结果 | 不作为第二份内容源保存 |

标题草稿为空时，已接受的文档保留上次有效标题。失焦或保存前读取草稿，原子执行交换或删除，避免丢失用户清空标题的意图，也避免把空标题作为有效源文本提交。普通字段更新同样先经过已定限长规则。

用户确定的端点连接位置纳入有效文档，编码见[连接点与端点改接](source-text.md#连接点与端点改接)。撤销历史和批量选集只保留在内存中，不增加多选持久化字段或已排除的手动折点字段。任何新增功能仍消费同一份有效文档，不从预览 DOM 反向推断源码。

### 载入与诊断流程

沿用[源文本校验流程](source-text.md#校验流程与诊断)，顺序为：

1. 识别文件结构、格式版本和字段边界；无法可靠识别的部分产生诊断。
2. 重复节点按文档顺序保留第一个，移除后续副本及其自身数据、出边，建立保留节点索引；不能用后出现的节点覆盖前者。
3. 取消目标不存在的连线；指向已保留重复 ID 的关系仍连接第一个节点。
4. 为缺失位置生成候选，保留已有有限坐标为候选；废弃层叠属性排除，不参与几何计算，尚不显示原始碰撞画面。
5. 解码字段、统一换行，按 Unicode 码点对超长字段硬截断。
6. 排除无法处理的节点或内容，构建有效模型并输出集中警告。
7. 按最终有效节点集再检查关系，排除所有关联无效端点的连线。
8. 按默认收起状态测量有效节点，局部避让并更新路径；用最终有效节点范围计算自动平移与缩放，使全部节点可见后展示。空图以原点为中心；删除或收起不触发全图收拢。

去重是针对源元素的处理，不能调用常规的按 ID 删除节点命令，以免误删第一个节点及其入边。随机坐标每次载入只补一次，后续渲染不重新抽取；保存后重开已有完整坐标也不再随机。

载入与诊断不自动写盘，不保存异常原文副本。只读字数工具使用下文的原始数据检查路径，不先去重、修复或截断。

### 操作分发与更新范围

外壳把用户事件转换为操作请求，逻辑先完成必要的旧焦点收尾，再更新有效文档与派生显示。各入口复用同一套规则，避免工具栏点击既触发收尾又重复删除。操作入口标记来源，用户请求与独立自动任务不能混用；已确认的用户操作及其必要联动结果通过同一个操作边界提交并记录。

| 事件 | 文档或状态变化 | 显示更新边界 |
| --- | --- | --- |
| 形状按钮 | 按点击前节点焦点决定换形或新增；先捕获上下文再处理原生焦点变化 | 换形目标消失时终止，不降级为新增；批量选集不误作单节点焦点 |
| 通用新增 | 捕获焦点与视窗，收尾后生成候选、自动贝塞尔边并避让，再聚焦 | 有冲突才移动目标或受影响邻居，不改写已有边；换形不调用此操作 |
| 单节点拖拽 | 指针位置换算为期望坐标，局部避让后提交 | 拖动中同步更新实际受影响节点与 SVG 路径，不等待松开，不进行整图排版 |
| 批量移动 | 对选集快照应用共同候选位移，作为刚性整体避让后提交 | 内部相对位置不变，可局部移动碰撞邻居，不改写边 |
| 批量删除 | 删除选集和关联边集合，同一边按 ID 去重后只处理一次 | 不删除其他节点，不级联或重接 |
| 批量复制 | 从操作前快照复制节点与全部关联边，分配新 ID 并映射选中端点 | 原有边保留，外部节点仅新增必要的出向副本边 |
| 文本编辑与收尾 | 限长、草稿接纳、交换或删除；同一节点内部切换字段不收尾 | 受影响字段、尺寸和连线；不把预览写回源码 |
| 删除 | 一次移除目标与全部入边、出边 | 清除对应卡片和线路，其他节点位置保持不变 |
| 工具栏建边 | 保存两次节点点击与连接点，完成后新增一条关系 | 只更新新边，不移动节点；未完成草稿不进入源模型 |
| 单击或双击边 | 单击建立对象焦点并保持说明框隐藏，双击再显示说明输入；先收尾旧对象 | 退出说明编辑后隐藏，不产生重复建边、删除或两份编辑会话 |
| 拖拽连线端点 | 更新指定端节点与连接点，保持边标识、另一端和说明 | 只更新该关系与派生索引，不移动任何节点 |
| Delete | 批量选集激活时删除选集及关联边，否则按单对象焦点删除 | 阻止该键继续执行文本删除；无焦点且无选集时不误删 |
| 撤销用户操作 | 应用最近一次可撤销用户动作的反向变更，恢复对应文档或页面状态；不写盘、不记录为新的普通用户编辑 | 重新生成受影响的预览、尺寸与线路；不单独倒退自动显示更新 |
| 展开、收起、媒体加载或外观尺寸变化 | 测量新外框，局部避让后一次更新画面 | 用户动作中的位移整体可撤销，独立异步更新不进入历史 |
| 平移、缩放 | 更新统一画布变换，所有图内元素等比变化，编辑焦点仍存在时保证目标可见 | 不设最小可辨识尺寸补偿，不写入节点坐标或因缩放触发避让；卡片内部滚动不误触画布移动 |
| 回到原点 | 按原焦点收尾规则取消对象焦点，再将图原点移到视窗中心 | 保留当前比例，不恢复 100%，不移动任何节点 |
| 查找输入与筛选 | 更新命中序列和数量，清除旧查找定位标记 | 不自动定位首项，不通过输入改变节点焦点或展开状态 |
| 查找上／下箭头 | 定位仍存在的上一／下一命中对象，替换当前查找标记 | 只突出当前定位对象，保留缩放和卡片展开状态，不自动选中、进入文字编辑或显示边说明框 |
| 编辑焦点或焦点对象几何变化 | 检查目标的可见范围，必要时更新画布平移 | 只跟随当前焦点，目标被删除或失焦后停止，不复用上一次对象 |
| 磁盘变化 | 丢弃当前会话未保存状态，重新载入 | 以新有效文档重建画面，不合并旧状态 |

长按、拖拽、文本选择和内部滚动共用手势判定，避免一次操作触发多个行为。长按阈值固定 1 秒；拖拽阈值等技术默认值由实现方确定。操作取消、节点删除或重新载入时撤销未完成的手势与异步更新，避免旧结果污染新文档。

### 画布视野与查找的技术接入

以下是落实 L7 的技术默认值，不增加新的导航功能或筛选项。外壳提供扣除可见工具覆盖区域后的可用画布矩形，定位与初始适配以该区域中心为准，不把节点居中到被界面遮挡的位置。按[外壳 S3](shell.md#s3-已确定的查找与警告布局)，左侧工具栏和右上方警告栏常驻，查找框在警告栏下方按需打开；三个区域均为浮层。技术上可用工具栏右侧、上方条带下缘以下的保守矩形计算适配和跟随，不改变画布实际绘制范围，也不为工具移动图中节点。查找框显隐或警告内容高度变化时更新测量；隐藏查找框不占遮挡范围，显隐不触发全图重新适配或改变用户比例。节点坐标仍是独立的图坐标，新建 5% 候选继续使用既定的创建时视窗快照。

#### 初始视野与比例

完成当前轮读取修复、默认收起状态的尺寸测量及局部避让后，取所有有效节点外框的联合包围盒，包括孤立节点与离原点很远的节点。令其宽高为 `Bw`、`Bh`，可用视窗宽高为 `Vw`、`Vh`；初始留白技术常量为每侧 24 CSS 像素，小视窗按尺寸缩减留白。缩放取 `min((Vw - 2p) / Bw, (Vh - 2p) / Bh)`，平移使包围盒中心对准视窗中心；不得因常用缩放下限而裁掉有效节点。边的路径和浮层不额外扩大“全部节点”的适配范围。

空图没有节点包围盒，采用图原点居中、比例 1 的技术默认值，不生成占位节点，也不增加恢复 100% 按钮。视窗尚无有效尺寸时延迟计算，避免除零。载入时按已知外框完成适配，不无限等待远程图片；用户接管浏览后，异步更新按局部避让与焦点可见规则处理，不反复把视野缩回全图。

初始自动适配仅是载入步骤。用户随后可调整缩放；不提供手动“显示全部”或“恢复 100%”命令、按钮或快捷键。回原点只调整平移。比例范围、手势与步长由开发方按实际交互调试，但不能以确保文字或控件可辨识为由强制提高缩放下限；卡片滚动、长按与画布手势互斥处理，不能让同一事件同时编辑和导航。

按 A4 使用一个比例变换图内全部可见元素，包括文字、线宽、箭头、说明框、焦点描边和端点控件，不设置固定屏幕线宽或控件尺寸补偿。点阵使用同一图坐标变换，仅由外观绘制，不加入有效图模型。节点尺寸与碰撞仍在图坐标中计算，屏幕测量须按当前变换还原；纯缩放不改变图内外框、连接位置或节点间碰撞关系，不触发局部移动。外壳工具与图内控件分开，工具栏、查找工具和警告栏不纳入图变换，配色读取当前主题。

#### 查找范围与命中

从当前有效内存模型建立只读派生索引，记录对象 ID、对象类别、文本字段与命中位置；包含未保存但已接纳的文本，节点删除或内容变化后同步更新。搜索输入先按已有焦点规则收尾旧对象，失焦导致自动删除的节点不能继续作为有效结果。隐藏笔记、标题、卡片内容和非编辑状态的边说明都不依赖预览或输入框是否挂载。

节点文本来自三个 Markdown 字段，包含其中的表格单元格文字与图片替代说明；边文本就是连线说明。Markdown 与公式使用原始字段字符串参与查找，不要求只匹配渲染后的 DOM；HTML 标签、ID、坐标、外观类名、诊断和界面文字不当作文档正文，也不读取外链资源做全文搜索或图片识字。不读取字段外的旧结构化表格，也不添加业务筛选条件。

筛选只使用节点与边两个选项；无选项时搜索全部，两者都选时同样是两类的并集，不解释为交集。技术默认使用不区分大小写的字面子串匹配，不引入正则或语义搜索；空查找词清空结果，不另外提供独立节点列表。内部按源文本对象顺序维护去重的命中 ID 序列，不渲染供点击定位的结果列表；可显示当前对象的只读片段和计数。

查询或筛选改变后仅重算结果并清除旧定位标记，不自动移动视野。用户通过上／下箭头按钮调用上一／下一定位；技术默认无当前项时“下一个”取首项、“上一个”取末项，之后循环切换，无结果时不执行定位。具体入口与快捷键见[外壳 S4](shell.md#s4-已确定的功能入口)，不额外提供点击片段或全局上下键定位。

定位前重新解析目标 ID，目标已删除时移除过期结果，不生成替代节点。节点定位取当前外框中心；边定位技术默认取当前可见说明框中心，无可见说明框时取显示路径的弧长中点，即使源说明非空也不引用隐藏框的旧测量位置。保持目标边的可见部分在视野中，不强制同时看见其两个端点。命中定位只做导航，并仅为当前定位对象应用统一焦点描边；切换结果清除旧查找标记，清空查找、目标删除或刷新时同样清除。标记不写入对象焦点或批量选集，不进入文字输入，不自动展开或收起卡片，也不显示边说明框；命中隐藏文字可显示结果片段，由用户按既定入口自行查看或编辑。

#### 居中、跟随与操作边界

设当前比例为 `s`、目标图坐标为 `q`、视窗中心屏幕坐标为 `c`，画布局部原点屏幕偏移为 `o`，平移量为 `t`；节点定位取 `q` 为外框中心，使用 `t = c - o - s × q`。回原点取 `q = (0, 0)`。这只更新画布变换，不能为实现居中改写 `data-x`、`data-y`。

节点或边获得编辑焦点时先检查可见性；编辑过程中，拖动、局部避让、卡片尺寸变化、用户缩放或可用视窗改变后检查当前目标。目标仍可见时无需移动，移出可见范围时重新居中；节点内文字输入时同时保证当前输入区域可访问，边说明编辑时以说明输入区为跟随目标。普通单击或双击已经可见的对象时不抢先移动画布，避免第一击后的视野变化破坏第二击命中。跟随优先平移并保留用户比例；目标大于视窗时不要求整个外框同时可见，保证操作区域可见并沿用内部滚动，不借此自动折叠卡片。

跟随只读取当前焦点，不为批量选集虚构单节点焦点。普通新建在旧视窗快照下生成候选、完成避让和焦点交接后再跟随；不能用跟随后视窗反算一次新的候选。批量复制仍只建立临时选集，不额外聚焦某个副本；批量拖动时按指针操作区域做必要的视野跟随，不改变选集内部相对位置，也不自动全图缩放。

拖拽与跟随必须共用一致的坐标变换：以起始图坐标和手势位移为依据，补偿本次视野平移，不能把程序平移误算为用户额外拖动而导致节点漂移。画面提交同步更新目标几何与视野，不先显示焦点目标丢失的一帧。

用户明确发起回原点、查找或空白画布导航时，按既定焦点规则先收尾并取消旧焦点，防止旧目标跟随立即覆盖导航结果；仍保有对象焦点的缩放操作则继续保证目标可见。载入与独立自动跟随不单独记入撤销历史；用户操作的同步视野变化与其操作合并记录，显式缩放、回原点与查找定位仍按 L2 记录用户展示操作。撤销恢复后的视野如与当前有效焦点可见性冲突，先满足可见性，不把派生跟随额外加入历史。所有状态均不持久化，刷新后重新自动适配。

### 节点形态创建与切换的技术接入

所有新增操作创建同一种节点数据结构；工具栏先捕获节点编辑焦点，再把 `round-rect`、`rect`、`diamond`、`parallelogram`、`circle`等外观类名交给换形或新增分支，不创建内容场景枚举或业务节点子类。原生 `class` 表达形态，内容元素描述内容本身，详见[形态源文本草案](source-text.md#节点形态引用草案)。无明确形态的通用新增操作采用圆角矩形 `round-rect` 技术默认值。

形态切换复用同一个节点与内容模型，仅替换持久化的收起形态引用。显示轮廓由收起形态和展开状态共同派生：展开时始终使用统一圆角矩形。普通展开／收起只改页面状态，不能将展开外观反写为所选形态。预览可以重新渲染，但不得从预览 DOM 重建或覆盖源文本，不执行字段转换、媒体筛选或正文清理。标题、卡片与笔记控件草稿也应留在原节点，不因预览重新挂载而丢失；若操作同时触发已定的焦点收尾，仍按原规则独立执行。

A1 的水平阅读区、形状标识与空笔记规则见[外观设计](appearance.md#a1-已确定的节点阅读区域)。标识与分隔标签不属于正文，查找仍只使用源字段。预览可省略空笔记区，展开编辑时仍保留可访问的输入控件；不因展示切换重置草稿。

按当前派生显示轮廓计算安全的内部内容区域与外框；长内容可滚动，不按圆形或菱形边界裁掉可访问内容。外框变化时局部避让，端点按原归一化位置投影到新轮廓，保持边标识、方向、目标与说明。一次提交形态引用、必要位置变化和派生几何；历史记录恢复形态及本次同步位移，不覆盖独立的后续自动操作。

### 批量选择与三种操作的技术接入

维护独立的节点 ID 集合 `selection`，与节点或边的单对象编辑焦点互斥。下列选择及落点方式是技术草案默认值，可按实际交互验证调整，不增加批量功能范围：

- 鼠标主键在空白处拖出选框，将与选框相交的节点加入本次选集，只检测节点，不选中穿过选框的边或说明框。Shift＋单击仍可切换节点选择；为区分框选与画布平移，平移暂采用按住空格拖动或鼠标中键拖动的技术默认值。可交互画面已无节点重叠，不提供遮挡穿透选择。
- 进入批量选择先独立完成旧焦点的编辑收尾，再移除已经失效的 ID；因此触发的空标题自动删除不并入后续批量命令的可撤销内容。批量选集中可有一个或多个节点，全部应用统一焦点描边，不将它们同时切换为文本输入状态，也不把它们的关联边加入视觉选集。
- 拖动选集内任一节点执行整组选集移动，单击已选节点保持选集，不同时进入正文编辑或触发长按展开；普通单击选集之外的节点退出批量选择并回到单对象编辑，点击空白取消选集。复制与删除快捷键读取当前有效选集，不复用历史选择或旧焦点，不提供工具栏按钮。
- 批量模式下 Delete 调用批量删除，复制通过快捷键调用 L3；回到单对象模式后继续执行 L1 的对象删除，不提供复制／删除按钮或对象菜单。形状按钮触发普通新建时若只有批量选集而无焦点节点，仍按无焦点节点规则居中且不额外连线，不执行批量换形，也不从选集中任取一个节点作为父节点。

执行批量命令前，先完成必要收尾并冻结当前有效选集 `S`、节点数据和操作前的边集合。空选集不产生变更或历史记录。批量操作只提交一次有效模型更新，不在界面上暴露一半节点已经处理、另一半尚未处理的状态。

**批量移动：** 捕获各节点初始位置 `pᵢ`，将指针位移换算成候选 `Δ`，对整个选集求无碰撞的共同位移 `Δ*`，最终 `pᵢ′ = pᵢ + Δ*`，任意两节点的相对位置保持不变。可局部移动碰撞邻居，但不能挤散组内成员。取消手势恢复本次预览中的全部位移，不遗留临时避让；边与源码顺序不变。

**批量删除：** 从操作前的边集合中收集至少一端位于 `S` 的全部边，按边 ID 去重，删除边集合与 `S`。内部边、跨选集边、自环、平行边统一处理，同一条边不因连接两个选中节点而删除两次；不沿关系扩展节点删除范围。撤销记录保存本次全部节点与被删边，整体恢复。

**批量复制：** 以操作前的有效数据为唯一输入，按以下顺序构建一个提交结果：

1. 按原节点的源顺序为 `S` 分配新的全局唯一节点 ID，建立映射 `f`；深拷贝三部分文本、属性、形态与样式引用和 Markdown 内容。正文不追加“副本”后缀，不改为默认标题，不共享可变内容对象；图片等外部资源继续使用原引用，不自动下载或复制资源文件。
2. 对操作前每一条至少一端位于 `S` 的边只处理一次。其起点 `u` 在 `S` 中则替换为 `f(u)`，否则保留 `u`；终点同理。为副本边分配新 ID，原样保留说明、路径外观和可选连接位置，不增加类型字段。
3. 两端都选中的边只产生一条副本到副本的边；不能分别在两端复制时重复生成。自环和每条平行边分别保留，不按端点去重。两端都未选中的边不处理，也不沿图递归收集更多节点。
4. 原边全部保留。副本边放入映射后起点的出向列表：内部边或出向外部边存入副本节点，外部入边的副本追加到原外部节点的出向列表。原列表中既有条目的相对顺序保持不变。不得再次扫描刚加入的副本边，造成递归复制。
5. 副本以原相对坐标为候选，整组寻找最近空位；原位会与原节点冲突，不能直接显示或提交。必要时局部避让，不生成层叠字段。副本按原源顺序追加并批量选中，单对象焦点为空，卡片默认收起。
6. 校验全局标识、端点和数据约束后一次提交。Markdown 图片与表格按原字段源码复制；不通过正文全局替换改写说明、图片链接或表格内容。复制不复用普通新建的默认标题、5% 定位和焦点连线流程。

每次批量命令及同步避让只生成一个用户记录。撤销复制同时移除全部副本及外部节点新增的副本边，并恢复连带位移；撤销移动或删除也恢复整次用户结果。后续独立自动变化使旧记录失效时，沿用 L2 规则，不复活自动删除对象或倒退独立自动避让。

### 用户操作记录与撤销接入

操作记录保留动作来源、当前文件会话标识、受影响的稳定对象 ID、前后有效值及恢复必要内容。采用针对受影响对象或页面状态的变更记录，不把整页预览 DOM、图片状态或所有派生数据作为可回滚快照。载入自动处理完成后建立可编辑基线，不将原始异常数据放入历史。

一次拖拽、一次端点改接或一次两阶段建边在提交时形成一个记录，不按每个指针移动事件生成撤销项；取消或没有实际状态变化的手势不产生记录。文本输入可按连续编辑会话合并，粘贴和输入法提交保留明确的动作边界；具体合并参数由实现方确定。新建带来的默认连线与聚焦、主动删除带来的关联边清理不能拆成独立自动记录。

撤销主动删除时，将节点、关联边、源顺序与该次位置变更作为一个事务恢复，检查标识、端点、文本及当前几何，不展示悬空边或重叠中间帧。用户操作引起的邻居位移纳入同一记录；独立自动变化不恢复，不能用整页旧快照覆盖它。不满足安全回放条件的复合记录沿用 L2 失效规则，无关历史保留。

文字输入与图操作共用应用操作历史，防止原生文本撤销和图级撤销同时消费同一个请求。记录可以包含被接纳的控件草稿，空标题草稿仍与有效源文本分离，未完成的输入法候选不作为独立有效文档状态恢复。空标题自动删除使用独立的来源标记调用公共删除函数，不写入可撤销删除记录；节点及关联边被移除时，同步清理该对象的输入会话与恢复入口。

历史有效性按以下技术草案维护，不依赖恢复整份旧文档快照：

- 在本次会话记录自动删除涉及的节点与边标识，用于阻止旧记录重建这些对象；只需标识，不保留其已删除正文作为恢复副本，刷新后与历史一起清空。
- 使会恢复这些对象、恢复其草稿或焦点、或生成悬空边的旧撤销记录失效；每次回放前重新检查对象与端点，不能只在当前栈顶做一次检查。旧输入控件或异步回调也不能重新提交已经失效的对象。
- 与自动删除无关的记录保持有效。复合操作若无法在保留自动删除结果及文档有效性的前提下原子回退，则整条记录失效并跳过，不拆成恢复一半内容的操作，也不清空其他有效历史。
- 如果用户主动删除了另一个节点，而其待恢复关联边所指向的节点随后被自动删除，不能借恢复前一条删除记录把该自动删除节点或悬空边带回来。

撤销成功后消费对应历史记录，不把该记录转入重做栈，也不把反向变更重新压入普通用户历史。后续新的用户操作按正常规则记录。应用内不暴露重做按钮、命令或快捷键；文本控件或依赖自带的重做不能绕过应用历史重新写入文档。

刷新立即废弃操作记录及正在执行的历史回放，并以新会话标识重建状态；晚到的旧回调不得重新加入历史。记录不写入 HTML、临时文件或浏览器持久存储，不能通过重新打开页面恢复旧历史。不维护重做历史或其他重新应用已撤销操作的通道。

### 局部避让与几何有效性

以节点当前可见外框的轴对齐包围矩形作为占用范围，包含边框，不包含阴影、焦点描边或连接点控制柄。两矩形内部有正面积交集即为冲突；边界接触暂不算叠放。圆角等形状也使用这一保守判定，边的路径交叉和界面浮层不属于节点叠放；A2 另外要求可见说明框通常互相避让并避开节点，隐藏框不占用空间；直线说明框空间不足时优先级低于节点，允许被节点遮挡。直线本身被节点遮挡也允许存在，不用节点层级命令处理。外观如需额外净间距，须通过统一的占用范围处理。

在图坐标中比较平移的欧氏距离。“最近”指相对本次期望位置，在其余节点约束下最近的合法落点，不是对整张图做全局最优排版。单节点为一个矩形，批量选集或副本为刚性矩形集合；搜索共同平移向量，不分别调整成员间距。

1. 先完成有效内容处理与当前尺寸测量。新建用 5%／居中候选，缺失位置只抽一次半径 5 的候选，复制使用原相对坐标，拖动使用指针期望位置。
2. 无冲突立即接受；有冲突时根据占用外框边界生成可行候选，按距期望位置由近及远检查。候选须对所有有效节点检查，不能只试一个固定方向。等距时采用稳定规则，技术默认优先右、下、左、上，再按坐标与源顺序打破并列。
3. 新建、拖拽和复制优先移动本次目标或整组选集。尺寸增长可优先保留当前编辑卡片的锚点，将碰撞邻居移至最近空位；继续冲突时只扩展到实际受影响的邻居，保持已接受对象为约束，避免来回推挤或无限循环。不依据业务边遍历全图排版。
4. 载入时按节点源顺序逐个接受或修正位置，相同外框重复检查应稳定。即使原文件全部节点重叠，也逐项求空位，不删除节点或改成树布局。画布不限制在当前视窗内，可以使用负坐标或移出视窗，不能因视窗狭小而允许叠放。
5. 批量操作期间选集是受保护的刚性单元，即使作为被避让的邻居也使用共同位移。使用同一版本的实际尺寸，不能混用新旧测量把成员拆开。
6. 对完整候选结果再次检查碰撞，一次提交坐标、尺寸与路径后绘制；拖拽中每个可见帧同样无重叠。测量或计算未完成时保留上一合法帧，不先显示覆盖别人的真实卡片再修正。取消手势撤回整次预览及其同步避让。

用户操作记录包含全部同步位移，展开、拖动或复制及邻居避让整体撤销。载入、字体或图片异步变化触发独立自动事务，不入历史；若它改变旧记录所依赖的几何状态，回放前须验证适用性，不覆盖独立自动结果。撤销后的画面也必须按当前尺寸通过碰撞检查。

静态 HTML 解析或仅检查坐标不能证明无重叠，必须结合实际外框。静态示例只在显式尺寸假设下核对几何，不能作为浏览器验证证据。避让改动坐标后保留在内存并标为待保存，不自行写盘；诊断可以说明受影响节点与原因，但不写成节点正文。

### 坐标、尺寸与连线路径

位置字段继续使用节点左上角的图坐标，屏幕位置通过画布变换计算。新建的 5% 间距按创建时浏览器内容视窗的 CSS 像素计算，再逆变换为图坐标；方向、中心对齐与焦点快照沿用[新建位置技术草案](source-text.md#新建位置与避让的逻辑接入)。

坐标由用户或 Agent 指定，也可由缺失候选和局部避让修正。更新或测量不能附带按布局场景、关系自动排版，但尺寸变化造成碰撞时必须避让；视窗变化不重新套用已有节点的新建候选规则。

连线路径根据节点坐标、尺寸、端点与连接点生成，并在持续拖动中随受影响节点实时更新 SVG 路径，必须可以表示平行关系、自环和有向回路，不为简化路由删边。建边与改接时，以鼠标位置到当前可见外轮廓的最短距离取边缘点，内部点击不直接成为端点。屏幕位置先换算至节点局部坐标；同距离存在多个候选时采用稳定顺序选取，命中容差与顺序由技术实现定义。

用户连接点按节点局部比例记录，移动节点时随节点平移；尺寸或外观改变时投影到新轮廓，不固定在过期的屏幕坐标上。卡片内容滚动不改变外轮廓上的连接点。没有连接点数据的既有关系仍可按自动路径显示，不因此判为无效。具体存储与异常处理见源文本草案；路由的中间折点由逻辑派生，首版不提供折点拖拽或说明位置拖拽入口。

卡片内部标题、正文和 Markdown 表格按外观及可见性规则组织；这些内部几何计算不得回写为其他画布节点的新位置。不增加数据图表系列渲染、手绘、包围区域或成员关系逻辑。

### A2 路径与说明框联动

采用已定的三种路径外观，缺省为贝塞尔曲线；创建时选择直角折线或直线只影响显示，不改变关系语义。新建节点自动附带的边也使用默认贝塞尔。复制、删除、重连仍按已有对象规则处理，复制与改接须保留路径外观。

贝塞尔与直角折线路由避开无关节点的当前外框；直线保留两端直接连接，并允许节点遮挡。此处是路径规划，不是按关系重排节点。连线交叉允许存在，通过可辨且尽量稳定的颜色分配区分；颜色不写入关系类型、说明或其他语义字段。

仅为当前进入说明编辑的边显示普通 HTML 输入框，说明为空也可以打开；未编辑的边即使说明非空也不生成可见框。显示时以路径弧长中点为初始中心，检测整个说明框与全部节点及其他可见说明框的相交情况，再沿同一所属路径调整中心。退出编辑后接纳合法文字并清除框的显示与占用，不保留隐藏障碍；当前单对象编辑通常只存在一个说明框，不增加多边同时编辑能力。可见框不自由离线漂移、不单独作为图节点，不能为避让而截断、缩小到不可读或隐藏正在编辑的框；直线空间不足时，允许由节点覆盖相交部分，这是显示优先级例外，不是删除说明。

可见说明框的内容换行、字号、主题和路径变化时更新测量；按可读初始宽度排版并根据全文增加宽高，不限定显示行数或用内部滚动隐藏其余文字。当前合法内容仍受 1024 码点输入上限约束。说明框的自动位置、尺寸、交叉颜色均是派生数据，与路径和节点使用一致的几何状态同步显示；用户文本变更整体按 L2 撤销，自动几何显示不单独记录历史。

直线说明框无法完全避让时，按[已确定的遮挡例外](appearance.md#直线说明框的遮挡例外)降低其相对节点的显示优先级，允许节点覆盖；中心仍在所属直线上，完整文本仍参与计数、搜索和保存。当前不解决该极端几何情况，不自动改变线形、搬动节点、增加引线或置顶说明框；说明框之间的常规避让规则保持，不承诺所有极端布局均可完全消除冲突。

可见说明框的单击、双击和 Delete 事件仍归属该边。查找按当前可见性定位：说明框未显示时取路径弧长中点，不能仅因说明非空而显示框或使用其隐藏位置。超大说明在编辑时通过画布平移缩放浏览，并跟随当前输入区域，不依赖把整框强行缩进视窗。L7 的视野跟随继续保证定位到目标区域，但不为上述暂缓处理的直线遮挡情况额外解除节点覆盖或新增恢复交互。

### 连线手势与删除事件接入

建边、端点改接、普通选择和文本输入分别维护会话状态。以下是依据已定产品行为采用的技术默认值，不新增关系语义或图形能力：

- 点击工具栏连线入口先收尾旧对象，再进入等待起点、等待终点的两阶段流程。节点内部点击由建边模式消费，不启动正文编辑或卡片长按；在无叠放画面中命中单个节点。完成后选中该边；Esc 或再次点击入口取消草稿，空白点击不创建无目标边。
- 单击边只改变选中状态并显示焦点描边，说明框保持隐藏；双击复用同一对象并显示说明输入，避免单击序列重复收尾。切换焦点后重新检查目标是否仍有效：原节点可能在失焦时删除，并同时删除本来要选中的关联边。退出说明编辑时先接纳有效文字再隐藏框，同一框内部操作不重复触发收尾。
- 为当前选中的边显示起点与终点控制点。命中控制点后仅启动端点改接，不启动节点拖拽；释放在另一个有效节点内才提交指定端和最近边缘点。释放在空白、取消手势或目标失效时恢复原关系，不删除原边或创建新节点。留在原端节点上释放暂不增加同节点换锚点功能。
- 起点改接时移动同一个边条目到新起点的出向列表，终点改接时只更新目标引用；保持边 ID、未改端连接点和说明。更新边及派生索引作为同一次内存提交。
- Delete 在对象层处理，优先于其内部文本控件的默认字符删除；不把退格、剪切或所有文字删除事件都转换成对象删除。删除后清除该对象的说明输入、焦点与端点拖拽；按键重复不转而删除另一个对象。物理键位与宿主事件的对应由实现方验证，不能仅按键帽文字推断。

说明文字编辑仍执行同一套码点限长，边失焦或保存前接纳有效说明。节点与边共用对象焦点分发，但空标题交换和自动删除仅用于节点；空边说明始终允许保留。手势与选中态不写入源文本，所有已提交的关系与连接点修改仍须手动保存。状态只驱动 A3 已定的统一描边与说明输入可见性，不产生悬停反馈或操作过程提示；选中边端点控件与实际几何更新保留。

### 文本与内容预览

三个节点字段复用已选 Markdown、公式与图片预览规则，关系说明走纯文本显示。计数使用 HTML 解码并将 CRLF／CR 归一为 LF 后的 Unicode 码点；原始 Markdown、公式标记、图片地址与内嵌编码都计入上限。

普通输入按整个结果判断是否超限；粘贴按“上限减去未选中文本长度”截取粘贴前缀，不删除既有后缀。输入法组合态留在控件草稿，提交时统一判定。具体事件接入继续沿用[输入长度控制草案](source-text.md#输入长度控制的技术接入)。

预览按标题、卡片和笔记区域生成，只为当前允许显示的内容渲染媒体。相对图片以外壳提供的原图资源基址解析；失败时显示已定常量，保留源引用。更新图片地址或刷新文档后，忽略旧请求迟到的结果。

### 保存与宿主接入

保存沿用[文件写入技术方向](source-text.md#手动保存与文件写入方案)：收尾草稿，完成当前测量与避让，校验有效模型，序列化全部有效内容和最终坐标，再由外壳组合必要文档结构、格式标识、当前版本的相对资源引用及源图后写入 HTML。保持源顺序，不保存公共程序、CSS、字体、工具界面、层叠、预览 DOM 或异常原文补丁，不自动升级资源版本。按[外壳 S2](shell.md#s2-已确定的文件操作)，新图先在内存编辑、首次手动保存时才选择位置，之后写回同一文件；不提供另存为。

打开其他图在当前页面替换文档。外壳完成目标读取与资源准备后，逻辑建立新的文件会话，清理旧图焦点、选集、历史和异步回调；文件选择取消或读取失败不替换成空图。当前文件身份、图片基址、公共资源版本、保存句柄与磁盘变化检测对象同步切换，不能继续按页面初始地址处理新图。S5 暂不展开，不新增自定义离开确认或自动保存流程。具体接入见[新建与同页替换](shell.md#新建与同页替换的技术接入)。

文件写入与磁盘变更检测是两项独立能力，需要分别在目标宿主验证。初期沿用已选文件写入方案，先验证 Chrome 与 Codex，再按实际结果适配更多 Agent 应用；本稿不把 Chromium 内核视为写入和监听均可用的证明，也不恢复上一轮后台读写架构。

写入失败或授权取消不能报告保存成功；一旦检测到磁盘变化，按既定规则刷新，不等待确认或合并。旧文件会话的手势、预览请求和未完成回调失效，不能在刷新后重新写入旧文档状态。

### Agent 提示词与只读检查工具

Skill 提示词需要说明首版使用源坐标，不提供图的自动排版；Agent 修改内容或关系时不能假设页面会自动整理节点。源坐标缺失只触发既定随机补齐，不承诺产生可读布局。

继续规划 TypeScript 只读字数检查工具，与浏览器复用字段识别、换行归一化、码点计数和上限定义。工具报告原始字段的对象标识、字段名、长度、上限和超出数量；重复标识通过出现序号或源位置区分，连线带起点信息。先检查原始内容，不能先硬截断再报告合规。

工具遇到无法解析的内容应报告检查失败，不自动修改文件、补坐标、去重或排版。命令名称与参数由开发方确定，实现后再补真实调用示例；当前没有可执行的新工具命令。格式、拓扑与操作结果的验证脚本同样使用 TypeScript，验证有效规则而非树专属限制。

| 查找过滤与隐藏内容 | 仅节点／边筛选，无筛选检索全部有效文本；收起笔记及未保存的已接纳文本可命中，节点和边更新、删除后结果不陈旧 |
| 命中定位 | 节点几何中心对准可用视窗中心；边目标可见；仅当前定位对象有查找描边，不改变对象焦点、比例、内容和关系，不自动展开卡片、进入编辑或显示边说明框 |
| 编辑焦点跟随 | 焦点节点新建、拖动、展开、避让、缩放或视窗变化后操作区域仍可见；边说明编辑同样可见，无旧焦点抢回视野或拖拽漂移 |
| 视野与源文本 | 查找、回原点、缩放和跟随本身不修改图坐标、不令文档变脏；若入口触发旧焦点收尾，其内容变更仍按原规则处理。不保存视野或查找状态，保存引发刷新后重新适配全部节点 |
| 无叠放与导航 | 平移缩放不改变图坐标，不提供层级调整或穿透选择；新建候选冲突时必须避让 |
| 编辑收尾 | 空白判定、交换、自动删除与主动删除一致；超限普通输入拒绝，粘贴只截本次内容 |
| 显示与源文本 | 区域可见性、固定展开尺寸和滚动正确，预览及图片失败提示不污染保存内容 |
| 异常输入与保存 | 分类处理结果稳定，只保存有效部分，排除异常节点及关联边；隐藏的有效内容仍保存 |
| 文件与刷新 | 分别验证实际写入和外部变更检测；任何磁盘变化丢弃未保存编辑，重开卡片收起且不重排 |
| 只读检查 | 对原始超限字段给出准确诊断，不修改文件，不把无法解析误判为成功 |
| A2 线与说明 | 默认贝塞尔，可创建直角折线与直线；曲线与折线绕开无关节点，直线可被遮挡；交叉边异色，编辑中的说明全文扩张、中心在线上，常规场景避让节点与其他可见说明框；直线空间不足时可被节点遮挡，不为该极端情况增加求解或恢复功能 |
| A3 统一焦点外观 | 节点、批量节点、边与当前查找定位复用粗描边，默认背景为蓝色；不把视觉标记当作文字编辑或删除目标，不改变几何占用；无悬停或额外操作过程提示 |
| A3 说明显示时机 | 单击边仅选中且可删除，双击才显示说明框，退出编辑隐藏；隐藏说明仍保存、限长和参与查找，隐藏框不参与避让 |
| A4 统一缩放 | 所有图内元素等比变化，无最小可辨识尺寸补偿；焦点跟随不自动放大，纯缩放不改写图坐标、不触发局部避让或内容隐藏，外壳工具不参与图变换 |
| A4 背景与主题边界 | 默认浅灰点阵不产生节点、关系、吸附或取整；工具栏、查找工具和警告栏配色由主题提供，默认白底黑边，不新增文档字段 |
| S1 资源与保存边界 | 图 HTML 仅含源文本、必要结构与资源引用；运行依赖来自本地固定版本公共包，普通保存保留引用且不写回生成界面，资源缺失不伪造空图 |
| S2 新建图 | 初始只有一个默认节点，无旧图内容、连线或保存目标；先保存在内存，首次手动保存才选址；打开或保存空图不补节点 |
| S2 同页打开与保存 | 成功打开替换当前图，取消或读取失败不误替换；保存、资源基址、版本、检测与历史均属于当前会话，无另存功能 |
| S3 工具遮挡与导航 | 常驻左侧工具栏、常驻右上警告栏及打开时的查找框均不随图平移缩放；初始适配、定位与跟随避开当前覆盖范围，显隐更新测量但不重排节点或重置比例，工具点击不透传 |
| S4 入口分发 | 有节点焦点时形状按钮只换形，无节点焦点时新增；手动建边先选线工具，自动连线和复制既有规则保留，无误新增或误建边 |
| S4 快捷键与浏览 | 撤销仅 Ctrl+Z／Cmd+Z，复制和删除仅快捷键；右上滑块与比例、回原点和查找控件遵守 L7，查找只经上／下箭头定位，不点击结果列表或输入即跳转 |
| SVG 连线实时跟随 | 在拖动未结束时连续检查路径与节点同步；覆盖单节点、批量、邻居避让、自环、平行边及平移缩放，不能拖动结束才重绘；公式未变时不重复排版 |
| L8 内容边界 | 图片与行列表格只从 Markdown 源码编辑和预览；没有原生 HTML 内容扩展、电子表格专用操作、手绘、分区、线框或模板；时序使用现有有向边 |
| 目标规模 | 在 10–200 个节点场景验证实际编辑、拖拽、展开和保存；测得瓶颈后再优化，不扩展到 1000 个以上的要求 |

L1–L4、L6–L8 按已定规则验收；不把已排除的手绘、分区、线框、模板或表格额外能力列为验收前置条件。算法、字段、依赖、事件与宿主验证由开发方落实。后续按布局场景的自动排版不作为首版完成条件。
