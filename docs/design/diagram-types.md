# 通用有向图、节点形态与内容场景

更新日期：2026-10-15。

本草案记录统一图模型、工具栏节点形态，以及 L8 确定的当前内容范围。原图类型和业务节点类型清单已取消；保留本文件路径以便现有引用继续使用。源文本表达见[源文本技术草案](source-text.md#技术草案)，交互规则见[逻辑设计](logic.md)。

## 已确定的产品原则

- 所有新建图都是通用有向图，不设置思维导图、流程图、自由画板等文档类型，也没有图类型选择或转换。
- 节点之间只有实际的有向边，不预设业务关系。用户通过节点内容、位置和边组织所需表达；说明文字不触发隐藏分类。
- 节点统一使用同一套卡片内容模型。圆角矩形、直角矩形、菱形、平行四边形和圆形是几何形态，不再区分图片节点、图表节点、判断节点、人员节点等业务类别。
- 工具栏提供节点形态与连线入口；不同形态可以自由混用，后续按需要增加可用形态。
- 已有节点可自由切换形态，保留所有内容、属性、资源引用和关联边，不设置内容转换或不兼容丢弃流程。
- 树和森林只是通用有向图的特例；回路、自环、平行边、多个入边、孤立节点和空图均允许保存。
- 继续遵守通用文本、焦点、删除、撤销与手动保存规则。通用新增标题为“新节点”，有原焦点时自动连出默认贝塞尔边，无原焦点时不连线；形状按钮有节点焦点时只换形，不触发通用新增。手动建边先选线工具，复制关联边规则保持。
- 禁止节点叠放，发生碰撞时局部避让；首版不做整图自动排版。未来只在手动创作完整可用后按具体布局场景设计自动排版，不恢复图类型字段。
- 图片等内容仍按标题、卡片内容、笔记归属和卡片展开状态判断可见性；不提供子树或分组折叠。

## 工具栏节点形态

| 初始形态 | 产品含义 |
| --- | --- |
| 圆角矩形 | 同一种通用卡片的圆角矩形外观，作为默认视觉基准 |
| 直角矩形 | 同一种通用卡片的直角矩形外观，与圆角矩形分别提供入口 |
| 菱形 | 同一种通用卡片的菱形外观，不自动获得判断或条件语义 |
| 平行四边形 | 同一种通用卡片的倾斜四边形轮廓，文字不倾斜，不自动获得输入输出语义 |
| 圆形 | 延续已确认的圆形外观，不自动获得开始、结束或参与者语义 |

工具栏提供上述五种形状按钮，有单节点编辑焦点时修改其形态，无节点焦点时才新增一个对应形态的节点；新增分支复用“新节点”、聚焦、候选位置和局部避让，换形保留原节点内容与边。手动创建连线须先选线工具；文件操作固定在工具栏最上方，撤销、复制、删除仅用快捷键。具体规则见[外壳 S4](shell.md#s4-已确定的功能入口)与[启动形态与工具栏](appearance.md#已确定的启动形态与工具栏)。

后续可以增加可用形态，具体 CSS、尺寸、形态类名和控件接入由开发方根据产品规则补齐。标题、正文、笔记、Markdown 图片与表格不由几何形态决定；所有支持的形态都必须保证内容可访问，不能永久裁去溢出内容。

所选形态用于收起显示；五种形态展开后一律是统一固定尺寸的圆角矩形，标题栏显示收起形状图标与名称。展开不改写保存的形态；展开中主动切换形态更新收起形状与标识，收起后显示新形状。具体阅读布局见[A1 外观方案](appearance.md#a1-已确定的节点阅读区域)。

形态切换引起当前可见外框尺寸变化时，按已有规则更新连接点与局部避让；不改变边的方向、端点对象、说明或节点 ID。用户切换及同步连带位移整体撤销。批量操作仍只有移动、删除和复制，复制保留内容和形态。

## 当前内容范围

L8 已按用户意见记录。图片仅使用 Markdown 图片语法，表格仅使用 Markdown 表格语法，不提供非 Markdown 的相关语法或操作能力。“平面单元表”经澄清指“Excel 表”，当前记录为 Excel 式行列表格，继续受仅 Markdown 与不提供表格额外能力的限制，不据此增加 Excel 文件读写或公式计算。

图片与表格源码都属于标题、卡片文本或笔记文本，随字段保存并计入已有长度上限。所有几何形态使用同一套内容，形态切换保留完整源码。编辑仍是在焦点内修改纯文本，退出焦点后预览；已有 Markdown、内联／块级 LaTeX 与图片失败提示规则继续适用。

时序当前完全通过现有有向边及纯文本说明表达，后续再根据实际需要优化。不增加专门的消息、时间轴或成员字段编辑器；用户可以在普通文本和 Markdown 表格中自行描述内容。

## 当前不支持的能力

- 手绘内容及笔画编辑。
- 基于表格的额外能力或非 Markdown 表格编辑。
- 分区、泳道区域、系统边界等专门展示能力；画布继续只执行禁止节点叠放与局部避让。
- 线框与内容模板。
- 旧草案中的原生 HTML 图片或结构化表格内容协议、数据系列与图表配置。

早期按飞书能力展开的场景清单不作为当前必须实现的范围。L5 已撤掉，L8 也未确认任何分组展示能力；不再保留相关候选项作为设计前置条件。逻辑规则见[已确定的 L8](logic.md#l8-已确定的内容范围)，本文件不代表相关交互已经实现。
